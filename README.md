# NotchPro downloads

Mac downloads for [NotchPro](https://github.com/ayushsingh82/NotchPro). Get the latest build from the [Releases](../../releases/latest) page.

- Apple silicon (M1/M2/M3/M4): `NotchPro-<version>-arm64.dmg`
- Intel Macs: `NotchPro-<version>-x64.dmg`

## First time opening

The app isn't notarized yet, so macOS warns the first time:

1. Drag NotchPro to Applications.
2. Right-click NotchPro, choose **Open**, then click **Open** again.
3. If there's no Open option: System Settings > Privacy & Security > **Open Anyway**.
4. Or run `xattr -cr /Applications/NotchPro.app` in Terminal.

Allow Calendar, Reminders and Spotify/Music when macOS asks.
